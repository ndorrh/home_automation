Guide: Scripts & Moving to Another PC

          

            
Moving to a 2nd Windows PC:

            
    
              
  1. Copy this project folder to the new PC (you may omit .venv, bin, and mailer/node_modules—first run rebuilds them automatically).
    2. 
              
  2. Double-click run.bat: it creates .venv, downloads bin/cloudflared.exe, installs Nodemailer, prompts once for Windows Firewall, hides .env, registers the SmartHomeAVServer logon task, starts silently, and opens http://localhost:8000.
    3. 
              
  3. Run .\.venv\Scripts\python.exe .\scripts\set_gmail.py once on the new PC so Gmail credentials are sealed with that PC's DPAPI key.
    4. 
            

            
Script Reference:

            
    
              
  • run.bat — Auto-setup + silent background start (terminal closes) + opens dashboard in browser.
    • 
              
  • run_console.bat — Foreground terminal mode showing live server logs for debugging.
    • 
              
  • check_status.bat — Shows PIDs, Scheduled Task state, HTTP reachability, and recent URLs.
    • 
              
  • scripts/fix_firewall.ps1 (runnable above) — Adds TCP port 8000 rule for Wi-Fi & Hotspot phones (triggers UAC on PC).
    • 
              
  • scripts/hotspot_control.ps1 (Hotspot ON/OFF above) — Auto-starts PC hotspot if internet stays offline, or toggle manually.
    • 
              
  • scripts/protect_env.ps1 (Hide/Unhide .env above) — Locks .env with Windows Hidden + System + Read-Only attributes.
    • 
              
  • scripts/set_password.py / scripts/set_gmail.py / scripts/decrypt_recording.py — Local CLI tools for password rotation, Gmail sealing, and offline file decryption.
